## 信息架构

Web固定在登录商家内工作。顶层导航为运营概览、门店与时段、预约与到店、顾客与卡务、资金账单、设备与视频、异常复核、日报与审计、员工与权限。管理员完整可见，操作员按权限隐藏入口；服务端仍须逐接口鉴权。概览只组合已有接口，统计加载失败逐项显示未知，不制造新的“总览接口已存在”假设。

小程序四个Tab为门店、预约、会员卡、我的。门店可公开浏览；创建预约、卡购买和个人记录前微信登录。门店卡展示所属商家，本人预约跨商家汇总；卡、信用、黑名单和欠费按所属商家解释。手机号独立可选，不能默认成为预约门槛。

## 必须保持的状态与业务含义

1. **一单一段**：每次选择一个60分钟时段，含今天共7天；相邻时段分别下单，同店有效相邻单合并通行窗口。已开始时段不能追购；续时仅预约紧接下一段。
2. **权益明确**：时段费/次卡/月卡每单只选一种。次卡每60分钟扣1次；月卡仍须预约占名额；超时不由卡覆盖。10次卡¥88、月卡¥199仅为视觉样例，可由商家实际配置，不能当成已确认经营价格。
3. **支付倒计时**：展示服务端截止 `min(创建+15分钟, 时段开始)`；样例17:40下单、17:55截止、18:00开始。到期重新取订单状态，不以本机倒计时直接宣告交易成功或失效。
4. **人数独立**：可预约余量不等于实际空位；估计在场须标“确认进出记录”。未知写“未知”，不能填0；摄像机无告警不等于无人。
5. **凭证独立**：未下发、下发中、生效、回收中、已回收、失败、未知；只有当前目标版本被设备确认才显示生效。提前30分钟下发不意味着提前入场。
6. **开门与入场独立**：受理中/结果未知不能写开门成功；开门成功不能直接写已入场。无可靠入场事件时，仅有窗口内有效预约和近5分钟成功开门记录后可“我已入场”。
7. **离场与账单独立**：结束锻炼确认离场；超时按分钟向上取整并单次封顶；在用显示预估，离场后显示最终/待复核。正常出门不能以支付为前提。¥10/小时、¥1/分钟、封顶¥30为既定演示规则。
8. **取消为多阶段**：接受申请→禁止新通行→回收不再需要的权限→退款/返次→完成。5分钟未知升级商家待办，仍显示取消处理中；不提前显示退款成功或释放名额。
9. **退卡与取消分开**：未使用可按资格自助申请，已使用交人工复核；冻结新预约权益、处理关联预约和设备回收后继续退款。月卡预约取消不等于退整卡。
10. **复核有证据**：展示事件发生/接收时间、身份方向和可靠性；疑似离场不自动结束或扣费。资金与结算修正需要管理员、原因及预览，保留原事实和追加流水。
11. **能力与来源逐项标记**：支付明确“模拟支付”；设备MOCK显示“模拟设备”；萤石接口/真机尚未验收时显示待验收。视频授权失败显示原因，不能把效果图中的播放器当作真直播已实现。
12. **隐私与权限**：不向会员开放店内视频；临时密码按需获取并默认遮挡；人脸入口仅在能力验收且用户独立同意后启用。图中删除顺序说明不代表已有删除请求；有实际请求才显示删除进度。

## 需要在开发中补齐的状态

| 场景 | 对应呈现/动作 |
|---|---|
| 未登录/登录过期 | 保留不敏感的选择上下文，微信登录/后台登录后重新确认；退出提示该账号已有登录全部失效 |
| 空列表/接口失败 | 具体空态、刷新/重试，不填假数据；不同卡片独立失败 |
| 名额已满/时间冲突 | 保留门店和日期，提示原因并重选；不能自动换时段或卡 |
| 订单过期/卡不可用 | 以服务端状态刷新，显示卡过期/冻结/次数不足/整段不在有效期的具体原因 |
| 欠费/信用限制/黑名单 | 指明所属商家、范围、恢复条件；欠费不取消已支付预约，也不限制物理出门 |
| 凭证下发失败/开门未知 | 展示原因、关联订单和商家待办；未知开门先核对，不提供盲目重复执行 |
| 暂停新入场 | 明确与“门店停业”区别；保留出门路径，按实际订单状态处理 |
| 配置被别人修改 | 412/428时刷新原数据并重新预览；不覆盖别人修改 |
| 复核被别人处理 | 刷新证据和任务状态，保留尚未提交的原因供重新判断 |
| 权限不足 | 按操作员权限显示只读/无权限；退款、信用冲正等仅管理员 |
| 视频不可用/无录像 | 具体显示离线、无存储、无录像或授权失败；不给会员端虚构直播 |
| 人脸资料删除 | 独立同意、请求状态、设备撤权和文件清理进度；失败可见，不假报已删除 |

## 交付与使用

打开 `index.html` 浏览，点击设计图查看原图。图像文件为imagegen生成的栅格设计参考，不包含可编辑Figma图层。中文小字、金额排版、具体状态及图内偶发生成误差应以本说明和原接口契约为准，开发前逐项校准。

`imagegen-prompts.json` 保存每张图的初始完整提示词，`imagegen-revisions.json` 保存定点修订提示词；最终PNG已采用修订结果。本地保存设计交付物；尚未编写业务代码，未调用真实支付、设备或微信接口。

已检查8张最终PNG均存在且图片尺寸有效，浏览目录的图片引用完整。逐图审阅并修正了连续预约拆单、已结束到店禁用开门、收款先于时段开始、星期与年份、详情页导航、已付费用标记和未经约定的退卡时限。未做浏览器交互、真机布局和读屏验证；静态设计不代表功能已实现。
